# Dunkin' · Rediseño web

Propuesta de rediseño del sitio de Dunkin' México pensada para una usuaria millennial: una persona práctica y con poco tiempo que quiere un café o un antojo **rico, rápido y sin complicaciones**.

**Diseño y desarrollo:** Yañez Cruz María Fernanda Daniela
Maquetación y Lenguaje Web · Diseño Gráfico Digital · Universidad La Salle

## Pantallas

| Archivo | Pantalla |
|---|---|
| `index.html` | Landing: hero, antojos por categoría, combos, promoción del día, Refreshers, sucursales y footer |
| `bebidas.html` | Bebidas: café y sin café, tamaños S · M · XL y ventana para personalizar |
| `refreshers.html` | Refreshers y bebidas frías con sabores y tamaños |
| `donas.html` | Donas & Panadería: premium y clásicas |
| `sandwiches.html` | Sándwiches & Snacks: precio en combo o individual y Extra bites |
| `combos.html` | Combos: combo del día, para ti, para compartir y pedido para la oficina |

## Características

- Diseño responsivo: escritorio (1512 px) y celular (430 px).
- Tipografía **Fredoka** (Google Fonts).
- Carrito compartido entre todas las pantallas de menú: se guarda en el navegador y se muestra en una barra fija.
- Sin librerías externas: HTML, CSS y JavaScript.

## Estructura

```
├── index.html y pantallas de menú (*.html)
├── css/   styles.css (base y componentes) + un archivo por pantalla
├── js/    carrito.js, main.js + un archivo por pantalla
└── img/   logo, fotos de productos y composiciones
```

## Cómo verlo

Abre `index.html` en el navegador, o publícalo con **GitHub Pages**: *Settings → Pages → Branch: main / root*.

> Proyecto académico. Dunkin' y sus imágenes de producto son marcas y propiedad de sus respectivos dueños.
